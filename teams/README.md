# Team workspaces

These folders hold planning and source material owned by non-engineering teams.
Product code belongs in `apps`, `extensions`, and `packages`.

- `agent/` — cross-team task briefs and coordination notes.
- `marketing/` — campaign planning, messages, and creative assets.
- `demo-video/` — demo concepts, scripts, storyboards, source footage, and exports.
- `growth/` — acquisition experiments, community activity, partnerships, and measurement.
