> Planning rubric: four criteria × 1–5 = 20 points. The official rubric and theme wording are not yet verified; do not present these as organizer requirements.

## 1. Criteria map

Every scope decision SHOULD trace to one of these rows.

| Criterion | What earns points | Our claim | Evidence on stage |
| --- | --- | --- | --- |
| **Core Requirements & Functionality** | Complete flows, no dead ends, everything shown actually works | Every required flow runs end to end: observe → warn → gate → escape → release → persist | Two packs working, offline fallback, reload keeps the budget |
| **Innovation & Theme Alignment** | A genuinely new angle, not a wrapper | A reinforcement agent with a *body*: deterministic local enforcement + LLM conversation, on a pack platform where the user authors commitments by talking | Natural language → pack draft → approve → live enforcement, in one session |
| **Technical Execution & Integration** | Integration depth, clean architecture, survives questioning | TypeScript kernel + Electron/Node.js + MV3 extension + loopback bridge, schema-validated at every boundary, cross-boundary fixtures, lease-based intervention | Architecture diagram, test output, kill the extension mid-gate and watch the lease release |
| **Usefulness & Agentic Experience** | Would a person keep it installed? Does the agent do real work? | Real tools with real effects, honest activity log, visible consent per capability, a voice worth keeping | The wishlist item and reminder that still exist *after* the demo, plus the log line proving the agent wrote them |

### 2.1 The behaviour loop as it exists today

Beats 0:50–1:30 need tools that do not exist yet. The loop underneath them does, and it can be shown without a browser extension at all:

| Time | Beat | What it proves |
| --- | --- | --- |
| 0:00–0:30 | `node scripts/simulate-site.cjs --site youtube.com` → ticks land, and Settings prints the records now in `events.json` | Sanitized signals, redacted persistence, a log a person can read |
| 0:30–1:10 | The pet stays silent while the level is low, then speaks on its own turn and changes face as the level rises | A slow cadence instead of per-event chatter; escalation with real thresholds |
| 1:10–1:40 | Dismiss the line, stop the simulator; the level decays | Every line has an escape; the pet does not stay angry at a finished session |

Say the provider out loud while showing it: it is **curated lines**, stamped `source: fallback`, and Settings names both. Nothing in this beat is generated by a model, and nothing was blocked, bought or deleted — there are no tools yet.

## 3. When time runs short

Cut optional work in this order: real-site adapter → grayscale → animation polish → pack-manager cosmetics. Removing the second reference pack changes product scope and requires an explicit decision plus updates to `docs/product.md` and the demo script.

**Never cut:** the escape hatch, offline fallback, the capability consent screen, honest activity logging, and the agent-drafted pack flow. Each is load-bearing for at least two criteria.

## 4. Honesty rules for the demo

- Demo mode MUST be visibly badged wherever a threshold is artificially lowered.
- Never present the sandboxed checkout as a real purchase, or a demo timer as real usage.
- Never present a curated fallback line as model output. The UI names the provider and the source of the last line; the spoken script must match what the screen says.
- Never claim an action the build cannot take. Until tools exist, the pet says things; it does not block, buy or delete anything.
- Never claim mobile, other browsers, or whole-web support.
- If something is mocked, say so in the same breath. The credibility of the privacy story depends on it.
- The bridge's only handler today is the mock in `apps/desktop/src/main/bridge/mock-handler.ts`. Any gate it raises carries `copy.source: "mock"` and `demoMode: true`, and the tray and Settings both say "mock handler" — a gate from it demonstrates the protocol, the lease and the escape, and nothing about policy, thresholds or the model. Saying "the bridge works" is honest; saying "the pack works" is not.
